## App Description

Ghost Wallet also exposes a web app at `https://ghostwallet.io/Wallet`. The project positions itself as a multi-asset wallet with Bitcoin mentioned in public-facing copy, while offering only limited technical information about how assets are handled.

## Analysis

The web presence is minimal, and the prior domain `ghostpoket.pro` redirects to `ghostwallet.io`. The site markets Bitcoin support but does not provide attributable source links for the wallet implementation.

During testing, the linked app flow displayed seed phrases, and supporting evidence was posted publicly on [X](https://x.com/BitcoinWalletz/status/2047128597799006661).

No public source code repository or technical documentation was identified for the web wallet implementation.

Based on WalletScrutiny methodology, this web app is classified as **nosource**.
