**Update 2026-10-30:** The [BlochsTech website](http://www.blochstech.com/) is still online and still shows an order form for the card at 19.95 EUR. We do not know whether orders are still fulfilled. The [terminal repository](https://github.com/BlochsTech/BitcoinCardTerminal) last received code in July 2016, and the developer's 2019 statement in the issue below is still the latest word on the project. The card still comes with keys created before it reaches the user, so the verdict {% include verdictBadge.html verdict="prefilled" type='short' %} still holds.

This hardware device lacks a screen or a button, this device cannot provide
basic security of hardware wallets but even worse, it comes with predefined keys.
According to their [info](http://blochstech.com/info):

> **How do I charge my card?**<br>
  [ ... ] transfer Bitcoin to your card's address. The address is in the letter
  you received with the card.

Their GitHub code was not touched since 2016 and 2019 the provider shared via an
[issue](https://github.com/BlochsTech/BitcoinCardTerminal/issues/14) that the
project was **dead**.
