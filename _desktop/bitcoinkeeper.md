## App Description

> Bitcoin Keeper is a multi-key, self-custodial Bitcoin wallet focused on secure storage, inheritance planning, and collaborative custody. The mobile app is the core wallet, enabling users to create advanced vaults, manage keys, and interact directly with their bitcoin. In contrast, the **desktop app is a companion tool—not a standalone wallet**—designed to interface with USB hardware wallets for secure signing and verification. Keeper supports Miniscript-based setups, time-locked keys, and privacy features like Tor and Electrum server integration. It is open source, avoids single points of failure, and offers both free and premium tiers tailored to users’ long-term custody needs.
