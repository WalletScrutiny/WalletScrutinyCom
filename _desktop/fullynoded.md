## App Description

> ​Fully Noded is a self-custodial Bitcoin wallet designed for iOS and **macOS (desktop)** platforms. It enables users to interact securely with their own Bitcoin Core nodes, offering features such as PSBT (Partially Signed Bitcoin Transactions) support, descriptor-based wallets, and compatibility with Lightning Network implementations like C-Lightning and LND. The application emphasizes privacy and security by leveraging Tor for encrypted communications and ensuring that private keys remain on the user's device.
