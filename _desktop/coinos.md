## App Description

Coinos is a web-based Bitcoin wallet supporting Lightning Network and Liquid. It is one of the longest-running Bitcoin web wallets, having operated since 2012. Available at https://coinos.io.

Key features include:

- **Lightning Network**: Send and receive Lightning payments
- **Liquid Network**: Support for L-BTC and Liquid assets
- **On-chain Bitcoin**: Standard Bitcoin transactions
- **Point of Sale**: Built-in POS functionality for merchants
- **LNURL support**: Pay, withdraw, and auth
- **NFC payments**: Tap-to-pay support
- **PWA**: Installable as Progressive Web App

Coinos can be used as:
- A custodial web wallet (using coinos.io)
- Self-hosted with your own backend

The front-end is open source (coinos-ui repository). The backend (coinos-server) is also available on GitHub for self-hosting.

**Custody note**: When using coinos.io directly, Coinos holds custody of funds. For self-custody, users should self-host or connect to their own Lightning node.
