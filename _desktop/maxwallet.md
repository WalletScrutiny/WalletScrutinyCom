## App Description

MaxWallet is a multi-platform cryptocurrency wallet distributed by MaxSwap, available for Windows, macOS, and Linux via direct download from [maxwallet.cc](https://maxwallet.cc/). Binaries are provided as an EXE installer for Windows, a DMG for macOS, and an AppImage for Linux. The app claims non-custodial storage with seed phrase access, support for Bitcoin and 40+ blockchains, and built-in swap and staking features powered by the MaxSwap platform.

## Analysis

The MaxWallet website makes no mention of open-source licensing and provides no link to a source code repository. A search of GitHub yields no repository attributable to MaxWallet or MaxSwap. Without access to the source code, the non-custodial and seed phrase claims cannot be independently verified. **As the source code is not available, this wallet cannot be verified.**
