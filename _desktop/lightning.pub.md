## App Description

Lightning.Pub is a Nostr-native Lightning node management system that enables sharing your Lightning node with others via Nostr accounts. As described by the project:

> The Nostr Native Lightning node, share your node with nostr accounts and connect easily to webapps.

Key features include:

- **Nostr-native**: Uses Nostr for identity and communication
- **Node sharing**: Share your Lightning node with family, friends, or community
- **NWC support**: Nostr Wallet Connect (NIP-47) integration
- **Web app connectivity**: Easy connection to Lightning web applications
- **Account management**: Create and manage Lightning accounts for different users
- **Start9 integration**: Available as a Start9 package

Lightning.Pub is designed for Lightning node operators who want to provide Lightning access to others without giving direct node access. Each user gets their own Nostr-based account with Lightning capabilities.

The software is built with Go and designed to work alongside existing LND or Core Lightning nodes.
