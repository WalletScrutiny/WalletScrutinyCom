## App Description 

> GoCoin is a comprehensive Bitcoin implementation written in Go, featuring a high-performance full node and an offline-capable wallet. The wallet is deterministic and password-seeded, allowing users to recreate their keys from memory without backups. It is designed for air-gapped environments and can run on minimal hardware such as a Raspberry Pi. The source code is publicly available under a permissive license, enabling users to audit and build the software themselves. However, there is no documented reproducibility guide or formal method provided to verify that the binaries are built from the source code. Users seeking reproducible builds should note this limitation.
