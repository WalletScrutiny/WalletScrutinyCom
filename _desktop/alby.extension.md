## App Description

Alby is a browser extension that brings Bitcoin Lightning and Nostr integration to the web. As described on their website:

> The Bitcoin Lightning Browser Extension that brings deep Lightning & Nostr integration to the web. Wallet interface to multiple lightning nodes and key signer for Nostr, Liquid and onchain use.

Key features include:

- **Lightning payments**: Send and receive Lightning payments directly from the browser
- **Nostr integration**: Sign Nostr events, manage identities
- **WebLN support**: Interact with WebLN-enabled websites
- **Multiple backends**: Connect to LND, Core Lightning, Alby Hub, or custodial Alby account
- **LNURL support**: Full LNURL protocol support (pay, withdraw, auth)
- **Liquid support**: Experimental Liquid network integration

The extension is available for:
- Chrome/Chromium browsers
- Firefox
- Safari

Alby can operate in self-custodial mode when connected to your own Lightning node (via Alby Hub, LND, etc.) or in custodial mode using Alby's hosted accounts. For self-custody, users should connect their own node or use Alby Hub.

The extension is open source under MIT license and has an active development community.
