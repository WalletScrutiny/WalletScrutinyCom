## App Description

> Bitcoin Core is the reference implementation of the Bitcoin protocol, offering full-node capabilities, wallet functions, and mining support. It enforces consensus rules, validates the blockchain, and enables users to send, receive, and store bitcoin in a trustless manner. It includes features like SegWit, transaction fee estimation, Tor support, and descriptor-based wallets.
>
> **Reproducibility:**
> Bitcoin Core is reproducibly built using [Gitian and Guix](https://github.com/bitcoin/bitcoin/blob/master/contrib/guix/README.md), ensuring that anyone can independently verify that binaries match the source code. Detailed build instructions are provided in the repository, and deterministic build outputs are confirmed across platforms through hash comparisons and signature verification.
