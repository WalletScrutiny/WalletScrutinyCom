## App Description

Bity Wallet is a Swiss-based cryptocurrency wallet application that provides access to multiple assets, including Bitcoin and others. 

## Testign and Analysis

We were able to [test](https://x.com/BitcoinWalletz/status/2006556366236954886) the app and were provided the 24-word seed phrase. When the seed generated by the app was exported to Electrum desktop, it [generated the same btc address](https://x.com/BitcoinWalletz/status/2006560092934779127). 

We did not find any claims regarding source availability, and a search on GitHub for the Google Play app ID [did not yield any relevant results](https://github.com/search?q=com.bity.wallet.production&type=code).

**The app is not source-available**.
