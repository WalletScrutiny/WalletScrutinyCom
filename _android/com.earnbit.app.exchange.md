## App Description

EarnBIT is an EU-licensed centralized exchange (CEX) offering spot trading for 150+ pairs,
quick token swaps, crypto deposits and withdrawals, staking, and a launchpad. It supports
BTC, ETH, XRP, SOL, and others. The platform stores user funds in an in-app wallet with
multi-layer security.

## Analysis

EarnBIT is a **custodial** exchange. The Play Store description states explicitly:

> "All user deposit assets are fully segregated from our operating funds."

And:

> "Store your holdings in our EarnBIT Wallet"

The platform holds user funds. There is no mention of private keys anywhere in the app
description. Investigation stops here.
