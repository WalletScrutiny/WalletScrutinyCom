## App Description

Paribu Self is a mobile cryptocurrency wallet application developed by Paribu, a Turkish cryptocurrency exchange, that operates independently from the main Paribu exchange platform. 

The app supports multiple blockchain networks including Ethereum, Avalanche C-Chain, BNB Smart Chain, Scroll, Linea, Base, Optimism, and Arbitrum, with Solana support planned. 

The wallet offers two modes: individual self-custodial wallets where users control their private keys, and multi-party wallets that use Multi-Party Computation (MPC) technology to enable joint asset management between multiple users. According to their website, the MPC implementation allows wallet creation and transaction signing without requiring specialized hardware, using only iOS or Android devices with internet connectivity.
