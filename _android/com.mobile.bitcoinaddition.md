## App Description

The Google Play listing advertises BITCOIN ADDITIONAL as a mobile wallet for the proprietary BTC Additional (BTCa) ecosystem, letting users store, send, and receive that asset while promising future support for more “coins issued on any blockchain”. Listed features include Shake-to-Pay offline transfers, contact-based payments, invoice-style requests for merchants, and Quan2um exchange integration plus planned Quan2um debit card support. The same description promotes budgeting tools, transaction history, and masternode-linked services tied to Quan2um, but it never references native Bitcoin compatibility.

## Analysis

Bitcoin Additional’s official site [btcadd.io](https://btcadd.io/) states BTCa is a “Bitcoin Fork on Proof of Stake” and repeatedly refers to it as “a coin that works as a fork of Bitcoin based on the Proof-of-Stake consensus algorithm”, confirming this wallet targets an altcoin rather than mainline Bitcoin (which remains Proof-of-Work). Because the Android app centers on Quan2um’s BTCa product and does not document compatibility with the Bitcoin mainnet.

Our [analysis](https://x.com/BitcoinWalletz/status/1991109120884425105/photo/2) confirms this. The address provided shows `BGntkYxoDYBLiFgJ1c3rsc7WpUhqpbN5nB` which **doesn’t match any of Bitcoin's encoding**.
