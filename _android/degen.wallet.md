## App Description

Degen Wallet is a Web3 wallet app that presents features for managing crypto assets, including token swaps, DeFi lending and staking integrations, NFT marketplace access, and dApp connectivity.

The app description emphasizes stablecoin payments (USDT/USDC), cross-chain swaps, and optional use of an NFC-based hardware wallet.
