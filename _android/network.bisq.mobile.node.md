## App Description

Bisq Easy is an Android application associated with the Bisq project that brings Bisq 2 mobile access to the Android platform through the Bisq network. It is designed around decentralized, privacy-preserving peer-to-peer communication over the Bisq ecosystem and is linked directly from Bisq’s official website and source repository. The app is presented as a mobile Bisq component rather than a standalone wallet, with the Play Store listing emphasizing communication and network interaction instead of direct custody or trading functions.

## Analysis

At the bottom of the Play description:

> This application does not include wallet functionalities for cryptocurrencies or fiat currencies and does not facilitate direct trading or financial transactions. It serves solely as a communication facilitator within the Bisq network.

This app is **not a bitcoin wallet**.
