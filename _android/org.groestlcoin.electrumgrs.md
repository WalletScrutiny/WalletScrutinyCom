## App Description

Electrum-GRS is an Android wallet for Groestlcoin, listed on Google Play by Hash Engineering Solutions. The official Groestlcoin page describes Electrum-GRS as a lightweight Groestlcoin wallet that uses Electrum-style servers and does not require downloading the full blockchain.

## Analysis

The Google Play listing describes the app as an "Electrum-GRS Groestlcoin wallet for Android." The official Groestlcoin Electrum-GRS page also describes it as a Groestlcoin wallet, and the public GitHub repository is titled "Electrum-GRS Groestlcoin Wallet."

We tested the app and posted the video on [X.com](https://x.com/BitcoinWalletz/status/2051491752331423753). During testing, the app kept closing and opening, so the Android app appears to be partly broken. This does not change the first failing review step, because the public evidence shows that this is a Groestlcoin wallet, not a Bitcoin wallet.

The app is a wallet, but it is **not a Bitcoin wallet**.
