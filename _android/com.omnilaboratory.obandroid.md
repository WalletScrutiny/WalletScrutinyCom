## App Description

OBAndroid is an Android wallet for the OmniBOLT protocol, which extends the Lightning Network to support Omnilayer assets (including USDT) in addition to Bitcoin. From the repository:

> OBAndroid is a self-custodial OmniBOLT Lightning wallet for android devices. It provides a platform for simple, instantaneous Bitcoin/Omnilayer asset payments.

Key features include:

- **OmniBOLT protocol**: Lightning Network extended for Omnilayer assets
- **Multi-asset support**: Bitcoin and USDT on Lightning
- **Self-custodial**: Users control their own keys
- **Instant payments**: Lightning-speed transactions

## Analysis

This project appears to be **obsolete**. The repository has not been updated since September 2023, and the latest release is marked as "testnet" from July 2023. The OmniBOLT protocol itself was an experimental extension to Lightning Network that has not seen significant adoption.

The app is not available on Google Play Store and requires manual APK installation from GitHub releases. Given the experimental nature and lack of recent development, users should exercise caution.
