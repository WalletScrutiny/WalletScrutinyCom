## App Description

Wallby is a self-custodial multi-network Bitcoin wallet that supports Bitcoin on-chain transactions along with assets on Liquid and Rootstock (RSK). It allows users to manage BTC, view Liquid-based NFTs, and swap tokens within the Bitcoin sidechain ecosystem under a single recovery backup.
