## App Description from Google Play 

FoxWallet is a non-custodial, multi-chain cryptocurrency wallet for Android supporting over 20 blockchain networks, including Bitcoin, Ethereum, Filecoin, BNB Chain, Arbitrum, Avalanche, Polygon, and others. The application enables users to manage multiple wallets and private keys locally, ensuring that sensitive data is never stored on external servers. It features integration with the Filecoin ecosystem, on-chain data monitoring, miner tracking, and support for F3 addresses. Security is enforced through local encryption and user-controlled asset management. Additional features include transaction acceleration or cancellation and flexible account switching via imported keys or seed phrases.
