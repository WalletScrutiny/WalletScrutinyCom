## App Description

Dana is a Bitcoin wallet designed specifically for accepting donations using Silent Payments (BIP-352). Silent Payments allow recipients to receive funds to a static address while maintaining on-chain privacy.

From the repository:

> Dana is a flutter app used for accepting bitcoin donations. It uses silent payments, a new static payments protocol, to receive donations while preserving on-chain privacy.

Key features include:

- **Silent Payments**: Receive donations without address reuse
- **Static donation address**: Share a single address publicly
- **Privacy-preserving**: Each payment goes to a unique derived address
- **Donation-focused**: Designed specifically for receiving donations

The wallet is experimental and not yet available on Play Store. It can be installed via:
- APK from GitHub releases
- Self-hosted F-Droid repository
- Obtanium

A Signet version is available for testing without real funds.

**Warning**: This wallet is still experimental. The developers recommend not using funds you aren't willing to lose.
