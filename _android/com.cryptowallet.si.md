## App Description

> Cryptowallet.si is a secure, open-source mobile wallet designed for alternative blockchain-based digital currencies. Built with transparency and user control in mind, it empowers you to manage your crypto assets independently and safely.
>
> - Full Ownership & Control - your wallet, your responsibility, with the wallet never storing your coins, private keys, or backup seeds.
> - Electrum Server Connectivity with 2–4 backend servers for blockchain communication, though you can set up your own for maximum reliability.
> - Open Source Transparency with wallet source code and recovery tools available on GitHub.

## App Analysis

The source code is publicly available at `github.com/CryptowalletSi/Cryptowallet.si` (Java, last commit October 2025), though the repository's license is categorized as "Other" rather than a standard OSI-approved license. The GitHub repository description explicitly names only "$LANA $TAJ" as supported chains; ARCO, NEVA, and NETKO support is confirmed via the official website. Bitcoin is not listed as a supported network in any official source.

## Analysis

This wallet does not handle Bitcoin or any Bitcoin-derived mainnet asset; all five supported networks are minor altcoins. The application is outside the scope of WalletScrutiny's Bitcoin wallet review criteria.

This app does **not handle Bitcoin**.
