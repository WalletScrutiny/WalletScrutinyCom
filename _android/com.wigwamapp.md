## App Description

Wigwam is a self-described self-custodial Web3 wallet that supports EVM-based networks (such as Ethereum, BNB Chain, and Arbitrum) and Solana, with features including multi-chain asset management, a built-in Web3 browser, and portfolio analytics.

The app claims to use Multi-Party Computation (MPC) for key management and to allow multi-device access, but its materials do not mention Bitcoin support or provide source code or reproducible build information.

## Analysis

Our [tests](https://x.com/BitcoinWalletz/status/2004434002531565818) confirm that **the app does not have support for the Bitcoin network**.
