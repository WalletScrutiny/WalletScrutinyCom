## App Description

From the Google Play listing:

> Turkey's new generation cryptocurrency exchange — buy and sell Bitcoin and 100+ cryptocurrencies with Turkish Lira, 24/7.

Kuantist is a Turkish crypto exchange based in Şişli, Istanbul. Users register via phone and ID verification, deposit Turkish Lira via bank transfer, and trade crypto through the platform.

## Analysis

Kuantist is a custodial exchange, not a wallet. Users buy and sell cryptocurrencies through the platform using Turkish Lira — there is no mention of seed phrases, private keys, or self-custody. The platform holds user funds and facilitates trades. No source code is available.

## Verdict

Kuantist is a **custodial cryptocurrency exchange**. Users do not control private keys.
