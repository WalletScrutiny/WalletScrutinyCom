## App Description

Leather is a self-custodial, open-source mobile wallet that supports Bitcoin and the Stacks Layer 2 network, allowing users to hold, send, and receive BTC while managing STX and SIP-10 tokens. The app enables users to sign Stacks smart contracts, interact with Bitcoin-secured dApps, and participate in Stacking and sBTC workflows directly from an integrated in-app browser. Private keys are generated and stored locally on the device, and the application is built from a publicly available source code repository.
