## App Description

Squirrel Wallet is a non-custodial, multichain wallet that keeps private keys under user control and provides on-device signing of transactions. The app exposes EVM-compatible features including token management, in-app swaps, NFT viewing, and a DApp browser across 150+ networks. "NUTS" is its native token and not Chaumain eCash related. The app provides transaction simulation and network diagnostics; 

A Bitcoin wallet is available to send and receive. 

However, its code is **not source-available**.
