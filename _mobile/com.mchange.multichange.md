**Update 2026-10-30:** The app is still gone from Google Play. Its
[archived store page](https://web.archive.org/web/20210922160649/https://play.google.com/store/apps/details?id=com.mchange.multichange)
from September 2021 describes an exchange service where you place orders to buy, sell or swap
cryptocurrencies, with support@multichange.net as contact. multichange.net now redirects to
multixchange.net, which returns a "Web server is down" error. Neither source says whether the
service holds coins for its users, so it stays {% include verdictBadge.html verdict="wip" type='short' %}.

**Update 2022-01-15**: This app is not on the Store anymore.
