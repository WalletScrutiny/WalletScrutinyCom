## Android

## App Description

**Claimed:**

Cheelee Wallet is an Android application that creates an account-based wallet without seed phrases, using a verification-free setup model rather than traditional key backups. 

The app supports holding and transferring multiple assets—including LEE, CHEEL, BTC, ETH, USDT, and various EVM-based tokens—across several supported networks. It also includes exchange functions such as buy/sell via bank card, token swaps, multi-portfolio management, and WalletConnect for interacting with external dApps.

## Analysis

We installed the app, with the awareness that it hasn't been updated since 2023. The main functions of the wallet wouldn't load. 

Going by the description, without the private keys provided to the user, this would be a custodial app. But the overriding meta verdict here is that this app is already **obsolete**.
