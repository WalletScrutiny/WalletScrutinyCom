## Android

**Update 2026-10-30:** Still custodial. eToro's crypto wallet, which used to come as the separate {% include walletLink.html wallet='android/com.etoro.wallet' verdict='true' %} app, now gone from Google Play, is reached from the [Wallet tab of this app](https://www.etoro.com/en-us/crypto/coin-transfer/), and users can send crypto from it to external addresses. eToro's [hosted wallet terms](https://www.etoro.com/wp-content/uploads/2025/06/eToro-EU-Wallet-Customer-Agreement-4-June-2025-Clean.pdf) say: "We securely store the private keys associated with your account [...] under our control." In July 2026 eToro [announced self-custody wallets set up from within the new app](https://www.stocktitan.net/news/ETOR/etoro-launches-new-app-ai-first-smart-and-mc7tf5mn8wm2.html), powered by {% include walletLink.html wallet='android/com.zengo.wallet' verdict='true' %} technology. We found no eToro page confirming that this wallet holds Bitcoin or how to reach it from this app, so the verdict stays {% include verdictBadge.html verdict="custodial" type='short' %}.

Etoro is used to speculate on assets more than to actually transfer them but in
the case of Bitcoin, according to
[the Help Center](https://www.etoro.com/customer-service/help/1422157482/can-i-withdraw-my-cryptocurrencies-from-the-platform#deadLink)
you can actually send Bitcoins from this app ... if you are in the right
jurisdiction ...
[further restrictions apply](https://etoro.nanorep.co/widget/widget.html?kb=156763&account=etoro#onloadquestionid=1306615492&deadLink) ...

So all in all this could pass as a custodial app.

As a custodial app it is **not verifiable**.
