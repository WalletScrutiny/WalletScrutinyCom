**⚠️ Warning:** Element Wallet has shut down. Its website no longer loads, and the team told users to [back up their seed phrase and import it into another Core-compatible wallet by Thursday, January 22, 2026](https://x.com/elementwallet), when its temporary access window ended. Do not keep funds in this app.

**Update 2026-10-30:** Element Wallet closed in January 2026 (see the warning above), so we mark both apps as defunct even though they are still listed in the stores.

## Android

## App Description

Element Wallet is a self-described non-custodial wallet that enables users to store and transfer CORE, BTC, and other supported assets while maintaining local control of their keys. The app includes staking features for CORE and BTC, as well as built-in access to dApps and blockchain-based encrypted messaging. It provides standard wallet functions such as sending, receiving, and managing assets through an interface designed for both new and experienced users.
