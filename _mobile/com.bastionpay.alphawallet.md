**Update 2026-10-30:** We now file this app as {% include verdictBadge.html verdict="custodial" type='short' %}. It is still gone from Google Play. An [archived copy of its store page](https://web.archive.org/web/20201021115838/https://play.google.com/store/apps/details?id=com.bastionpay.alphawallet) from October 2020 names Ard Financial Group as the developer and says "Asset security and escrow are held to banking standards", which describes the provider holding the coins, not the user. The developer website it links, [ardcoin.com](https://www.ardcoin.com), is still online but now presents Ardcoin, a "Decentralized Loyalty" product.

**Update 2021-12-03**: This app is gone from the Store.
