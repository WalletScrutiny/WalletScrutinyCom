**Update 2026-10-30:** The app is still gone from Google Play, but the Internet Archive kept its [store page from November 2020](https://web.archive.org/web/20201109021448/https://play.google.com/store/apps/details?id=com.stash.wallet). It described a BTC and BCH wallet with "100% control over your own private keys", a 24-word BIP39 backup and BIP47 payment codes. We found no source code for the app: the [StashCrypto GitHub account](https://github.com/StashCrypto) has only a Jekyll theme fork and an RFC repository, both last changed in 2018, and the [Open-Transactions](https://github.com/Open-Transactions) project it built on publishes libraries, not this app. A self-custodial wallet without source is {% include verdictBadge.html verdict="nosource" type='short' %}. The developer's website stashcrypto.com now redirects to an unrelated TRON energy rental service, and stashwalletapp.com no longer resolves.

**Update 2021-11-17**: This app is not on Play Store anymore.
