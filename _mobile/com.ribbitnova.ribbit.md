## Android

## App Description

Ribbit is described as a non-custodial multichain wallet and payment app built on Supra's Layer 1 network. The Play Store listing says users keep control of their funds through their keys while using features such as token storage, swaps, staking, payments, dApp access, NFT support, portfolio tracking, and index investing.

The listing explicitly claims support for Bitcoin:

> Supported chains include Bitcoin (BTC), Ethereum (ETH), Arbitrum (ARB), Polygon (POL), BNB Chain (BNB), Avalanche (AVAX), Optimism (OP) and more.

The Ribbit website also describes the app as a multichain wallet where users can store, send, receive, stake, and swap crypto tokens. It claims self-custody with the statement that users hold the keys and Ribbit does not have access to the user's funds.
