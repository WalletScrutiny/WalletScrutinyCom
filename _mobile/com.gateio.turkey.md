## Android

## App Description

Gate TR is a mobile application that provides access to Gate Türkiye’s cryptocurrency trading platform, allowing users to buy, sell, deposit, and withdraw supported crypto assets through an account-based system. The app requires user registration, identity verification (KYC), and operates under Turkish regulatory and compliance frameworks. User funds are managed through the platform, with fiat transactions handled via integrated banking partners and third-party payment service providers. The application functions as a custodial exchange interface rather than a self-custody wallet, with trading conducted via platform-managed orders and balances.

## Analysis

Gate Türkiye’s user agreement contains multiple custody indicators consistent with an account-based exchange rather than a self-custody wallet: it repeatedly defines Gate Türkiye as a “Kripto Varlık alım satım platformu” and describes user activity as placing orders (“Emir”) executed on the platform, and it explicitly states that user fiat is held with partner banks and that fiat services are delivered through third-party providers rather than the user directly controlling funds and transaction rails.

Translated from Turkish:

> “Kripto Varlık alım satım platformu” → “crypto asset buying/selling platform”
> “Emir” → “order”
> “Kullanıcıya ait nakit ... çözüm ortağı bankalarda tutulmaktadır” → “User cash is held at partner banks.”
> “Nakit ve itibari para hizmetleri ... üçüncü taraf hizmet sağlayıcı tarafından sunulmakta” → “Fiat cash and money services are provided by a third-party service provider.”

This is a **custodial** platform.
