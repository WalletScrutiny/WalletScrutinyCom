## App Description

VeraBit is a closed-source Bitcoin wallet published for iOS by TATSEN PAZARLAMA GIDA SANAYI VE TICARET LIMITED SIRKETI. Its [App Store listing](https://apps.apple.com/us/app/verabit-bitcoin-wallet/id6752948564) describes it as a self-custody wallet that stores keys locally on the device, and claims support for Taproot, SegWit and Legacy address formats, biometric security, multi-signature, and importing existing wallets. We did not find an Android counterpart. Moreover, it's homepage is currently 404.

## Testing and Analysis

We were not able to test the app: it is published only for iOS and we have no iOS device, so we cannot independently confirm any of the wallet functionality claimed in the listing.

The following are established facts:

- The app is available only on the App Store; we found no Google Play counterpart and no listing under this developer on Google Play.
- No source code is published. We found no repository under the developer's name or matching the `com.bitxwalet.production` identifier.
- The developer website and privacy-policy URL shown on the App Store, `https://bitx-bitcoinwallet.com/privacy`, returns "404 Not Found" on every path (a default Apache error page).
- That domain was registered on 2025-09-24 at GoDaddy, on a one-year term — five days before the app's 2025-09-29 release.

On iPhone, App Store binaries cannot be independently reproduced or audited, so the burden of proof rests on the provider to show how the app can be audited. The developer claims that VeraBit is a self-custodial Bitcoin wallet, but publishes no source code that would allow its claims or implementation to be audited. We therefore assign the verdict **nosource**.

We found no scam-blocklist entry and no user reports of lost funds, so we do not label the app fake. The domain and developer irregularities noted above are recorded as warning signs, not as evidence of fraud.
