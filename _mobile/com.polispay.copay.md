**⚠️ Warning:** PolisPay appears to be out of business. Its domain is parked for sale and its X account no longer exists.

## Android

**Update 2026-10-30:** The app is still gone from Google Play. www.polispay.com now redirects to a [GoDaddy page offering the domain for sale](https://www.polispay.com), polispay.org returns a Cloudflare error, the [PolisPay X account](https://x.com/PolisPay) does not exist anymore, and the [polispay GitHub organization](https://github.com/polispay) holds only the Polis coin repository, last pushed in October 2021, which points to github.com/polischain. We now list the provider as defunct. No wallet source code ever surfaced, so the verdict {% include verdictBadge.html verdict="nosource" type='short' %} stays.

**Update 2022-01-25**: This app is not in store anymore.

Given its app ID `com.polispay.copay` this app appears to be a clone of
{% include walletLink.html wallet='android/com.bitpay.wallet' verdict='true' %}
which used to be called "Copay".

In the app's description we read:

> A unique wallet based on mnemonic phrases and public and private extended keys
> PolisPay wallet is impossible to hack.

which sounds like a claim to be non-custodial. Let's see if there is source code
somewhere ... nope. No mention of its source code or a repository.

This app is **not verifiable**.
