## App Description

Theya – Bitcoin Wallet is an iOS application that provides self-custody Bitcoin vaults with multi-signature support. Theya offers an iOS app plus a web application for vault management/signing; the official site highlights “Download iOS App” and web “Create Account” access and does not provide any native desktop client download. The app/platform integrates with common hardware signing devices—Coldcard, Trezor, Ledger, and Foundation—documented in their [help center](https://help.theya.us/en/articles/9280279-what-hardware-wallets-does-theya-support). Collaborative multisig vault setup and operating procedures are described step-by-step in [Theya’s documentation](https://help.theya.us/en/articles/9280108-how-to-create-a-multisig-vault). 

When spending from a vault, Theya’s workflow sends device-specific signing instructions and opens a browser-based signing interface, with guidance for supported [hardware wallets.](https://help.theya.us/en/articles/9280184-spending-sending-bitcoin-from-your-vault)
