## App Description

Dito Wallet is a cryptocurrency wallet application associated with the DitoBanx platform. It enables users to store, send, and receive supported digital assets, including Bitcoin (BTC), through a mobile interface. The app provides wallet management features such as balance tracking, transaction history, and QR-based transfers.

Dito Wallet is integrated with DitoBanx financial services, which include crypto-to-fiat functionality and related financial products. Depending on the selected features, asset custody and transaction processing may involve platform-managed services rather than purely local key storage.
