## App Description

Satsigner is not distributed through Google Play or the Apple App Store. The APK is published on
[GitHub Releases](https://github.com/satsigner/satsigner/releases), and the website's
[download link](https://satsigner.com/apk/) points there. All releases so far are marked as
pre-releases. The first release with an APK was v0.3.0 (2026-04-27); the latest is v0.3.6
(2026-06-10).

The developer describes it on its [GitHub repository](https://github.com/satsigner/satsigner) as a
"Privacy-first Bitcoin signer with complete UTXO control". Per the
[README](https://github.com/satsigner/satsigner#readme), it is built with Expo and the Bitcoin
Development Kit, and supports single-signature, multi-signature and watch-only accounts on mainnet,
testnet and signet. The source is published under the MIT license.

## Testing and Analysis

All eight releases on GitHub (v0.2.1 to v0.3.6) are marked as pre-releases, and GitHub lists no
latest stable release. Since no versions have been officially released, we have not reviewed it yet.
