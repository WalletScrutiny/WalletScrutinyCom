## Android

## App Description

Haqabi Wallet is a multi-chain cryptocurrency wallet application supporting Bitcoin, Ethereum, HAQQ (ISLM), Tron, BNB Chain, Cosmos, Solana, and other digital assets. The application integrates cryptocurrency swap functionality and fiat on-ramp services for purchasing digital assets with local currency. The wallet markets itself as non-custodial with private keys stored encrypted on the user's device using AES algorithms, and includes a "seedless recovery" feature that allows wallet restoration without traditional seed phrases.

## Analysis

The application claims to be a "Secure Non-Custodial Crypto Wallet" where users *"maintain complete control over your crypto assets"* and "no one can freeze your funds." The description states that "Your private keys are securely stored on your device and encrypted with advanced AES algorithms" and advertises a "seedless recovery" feature that allows users to "recover your wallet without a seed phrase".

[No source code](https://github.com/search?q=%22com.haqabi.mobilewallet%22&type=code) repository was found in searches for "Haqabi Wallet github", "Haqabi Wallet source code", or "com.haqabi.mobilewallet". While the related HAQQ Network has open-source repositories, Haqabi Wallet appears to be developed as a closed-source application by Haqqex Ltd. Without access to source code, the claims about private key management, encryption implementation, and the "seedless recovery" mechanism cannot be independently verified or audited.

**We tested the app:** [Testing documentation](https://x.com/BitcoinWalletz/status/1990681913871438151) shows the 12-word seed phrase provided by Haqabi fails to import into Electrum Desktop using standard BIP39 derivation paths (p2pkh, p2wpkh-p2sh, p2wpkh). The wallet address generated by Haqabi (`bc1qdt80cpl7u55tswdk88npd03v9l0g4e9uen33vv`) does not match any of the addresses generated in Electrum from the same seed phrase. This proprietary implementation creates vendor lock-in, preventing users from independently accessing their funds with standard wallet software.

The combination of proprietary "seedless recovery", inability to use the seed phrase in standard wallets, and lack of source code means users are entirely dependent on Haqabi's application to access their funds. The verdict is **custodial**.
