**Update 2026-10-30:** TronWallet is gone and its successor app changed again.
The team announced the Klever App as "the 4th generation crypto wallet system
developed and designed by the team behind TronWallet", restored from the
TronWallet 12-word seed
([Klever blog](https://klever.substack.com/p/klever-app-is-live-on-app-store-and)).
That first Klever app,
{% include walletLink.html wallet='android/cash.klever.blockchain.wallet' verdict='true' %},
is itself removed now, and Klever's current wallet is
{% include walletLink.html wallet='android/finance.klever.bitcoin.wallet' verdict='true' %}.
The old website tronwallet.me no longer serves a working page. The only code we
found is a 2018 GPL-3.0 copy of the app at version 1.0.5
([CryptoSpaces/tronwallet-mobile](https://github.com/CryptoSpaces/tronwallet-mobile)),
two years older than the last release 3.4.5, so the verdict stays
{% include verdictBadge.html verdict="nosource" type='short' %}.

The wallet is not listed on Google Play anymore and as their website forwards
the visitor to the
{% include walletLink.html wallet='android/cash.klever.blockchain.wallet' %}
since long, one appears to be the successor of the other.
