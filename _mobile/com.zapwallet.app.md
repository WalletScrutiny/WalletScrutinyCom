## Android

## App Description

The app claims multicurrency support as well as "full custody" (of the user).

## Testing and Analysis

We tried two times to test self-custody markers, first by importing an existing 12-word seed phrase to the app, and second, by creating a new wallet on the app itself. 

In the first [test](https://x.com/BitcoinWalletz/status/2004477801852985690/photo/1), we imported the 12-word seed phrase onto the app, however the btc address generated by the app, did not match any of the addresses that it was supposed to generate. 

In the second [test](https://x.com/BitcoinWalletz/status/2004481048697303187), we generated the seed phrases from the app itself and imported it using Electrum 4.6.2 using BIP-39 and derivation path: `m/84h/0h/0h`. Again, none of the addresses matched. 

**Implication:**

For a Bitcoin wallet claiming "full custody of the user", importing the seed into a reference implementation like Electrum should deterministically reproduce the same addresses (given the correct derivation path). The mismatch indicates that the app either:

 - uses a non-standard or undocumented derivation scheme, or
 - does not derive Bitcoin addresses solely from the exported seed, meaning the seed is not sufficient to control funds.

Under WalletScrutiny methodology, this is sufficient to reject self-custody claims, as users cannot independently reproduce or control their Bitcoin keys using standard tooling.

We marked this as a custodial service and contacted the provider via this [x.com post](https://x.com/BitcoinWalletz/status/2004485863208874060).
