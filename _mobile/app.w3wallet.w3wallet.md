## App Description

W3 Wallet is a multichain DeFi wallet published by W3 Wallet Tech. The Play Store description calls it "Your self-custodial DeFi super-wallet" and says "your private keys never leave your device". Under "SUPPORTED NETWORKS" it lists Bitcoin first, followed by Ethereum, Arbitrum, Optimism, Polygon, BNB Smart Chain, Algorand, Solana, Tron and TON. Features include swaps, lending through Aave, Folks Finance, Compound and Morpho, yield vaults and quests with token rewards.

## Analysis

- **Bitcoin support.** We rely on the Play Store description, which lists "Bitcoin" among the supported networks. No other source was available to confirm it (see below).
- **Custody.** The description claims the wallet is "Truly self-custodial – your private keys never leave your device". We found no terms or help pages from the provider that say otherwise, or that say anything at all.
- **The provider's web presence is gone.** The website [w3wallet.app](https://w3wallet.app) now shows a GoDaddy placeholder page. The listed privacy policy, `https://api.w3wallet.app/policy`, did not respond when we tried to load it. An [archived copy of the website from May 2025](https://web.archive.org/web/20250512141456/https://www.w3wallet.app/) described a "New Non-Custodial Multichain Wallet" to "Send, receive, and store tokens from 8+ blockchains", but said nothing about keys or source code. The app was last updated on Google Play on 2025-10-21. The iPhone version, `app.w3wallet.wallet`, is already listed on WalletScrutiny as removed from the App Store.
- **Source code.** The archived website does not link to any code repository. A GitHub repository search for "w3wallet" returned only unrelated hobby projects. A GitHub code search for `app.w3wallet` found only third-party wallet lists and our own listing. A GitHub organization called [w3wallet](https://github.com/w3wallet) has only one repository, "Token assets for w3wallet", last updated in 2023. It has no app code, and we could not tell whether it belongs to this provider.

We found no public source code for this app, so the provider's claim of self-custody cannot be verified. The app is [closed source](/methodology/#nosource). With the website parked and the app no longer updated, the project may have been abandoned.
