## App Description

Rubicon Wallet is a cryptocurrency wallet application that claims to support multiple digital assets, including Bitcoin, Ethereum, and Litecoin. According to its description, the app provides features such as sending and receiving cryptocurrency, biometric authentication, password protection, and encrypted data storage. It also claims to offer a user interface for managing balances, viewing exchange rates, and performing transfers across supported assets.

## Testing and Analysis

We tested the app and posted the [video on x.com](https://x.com/BitcoinWalletz/status/2050165151845011946). There is Bitcoin support and the seed phrases were provided.

We did not find however, any claims regarding source-availability. We searched on GitHub and [did not find any relevant results](https://github.com/search?q=%22ua.rubicon.crypto.wallet%22&type=code) pertaining to the app id `ua.rubicoin.crypto.wallet`.

This app **does not share its source code**.
