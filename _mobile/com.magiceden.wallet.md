## App Description

Magic Eden Wallet is a multi-chain crypto wallet primarily designed for Solana, Bitcoin, and other supported networks. 

## Analysis

We did some [testing](https://x.com/BitcoinWalletz/status/1996786008927752441) and found that the app supports Bitcoin only when importing an existing seed phrase — it does not create a native Bitcoin wallet by default. 

When importing a Bitcoin seed phrase from another wallet, the Bitcoin address generated by Magic Eden Wallet does not match the address derived by the original wallet, indicating a derivation path mismatch or non-standard implementation. This mismatch can cause users to believe they have restored their Bitcoin wallet when the app is actually generating a different, unrelated address.

Moreover there are numerous reports of funds being lost.
