## App Description

bit21 is a Bitcoin-only Android wallet for on-chain payments. It sends and receives BTC using standard Bitcoin addresses. It offers coin control, custom fees, and time-locked vaults. The developer publishes MIT-licensed source and claims local keys.

## Testing and Analysis

The [Play listing](https://play.google.com/store/apps/details?id=com.bit21.wallet) claims on-device keys and no account requirement. Its [public repository](https://github.com/bit21org/bit21-wallet) uses an MIT license. The repository's last change was April 28, 2026. Google Play lists an update on June 21, 2026. We have not matched that build to published source.

The [website](https://www.bit21.app/) says native iOS is coming. iPhone users currently use its browser app.
