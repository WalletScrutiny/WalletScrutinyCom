## App Description

> ActPass Wallet is an extremely fast and safe multi-currency crypto wallet, focused on usability and perfect storage of all crypto assets.<br>
> A comprehensive digital asset management platform.<br>
> Safety first.<br>
> Accounts adhere to strict security standards, including multi-level verification to protect accounts.

ActPass is the wallet and marketplace of the blockchain game SERAPH. This iPhone app is published by Artal Internet FZ-LLC and carries the same description and version number (2.2.2, October 2025) as the Android app {% include walletLink.html wallet='android/com.actoz.actpass' verdict='true' %}. The iPhone app of that listing, published by Davox Technology AG, is no longer in the App Store, so this app takes its place.

## Analysis

- **Bitcoin support.** The Android app's description promises to make it "easy to withdraw/deposit USDT/BTC/ETH".
- **Custody.** The description talks about protecting "accounts" with "multi-level verification", not about keys. Our review of the Android app found sign-up with a Google account and no option to access, back up or restore private keys. The SERAPH team [credits game rewards](https://medium.com/@seraph_cryptogame) "to players' ActPass wallets", and runs ActPass support through a ticket portal at app.actpass.com.

ActPass is an account with the provider, not a wallet whose keys the user holds, so this app is {% include verdictBadge.html verdict="custodial" type='short' %}, like the Android app.

**Custodial: The provider holds the keys**
