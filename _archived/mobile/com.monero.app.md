## Analysis

Monero.com by Cake Wallet is a Monero-only wallet. Its open-source repository, [`cake-tech/cake_wallet`](https://github.com/cake-tech/cake_wallet), describes the product as "a noncustodial Monero-only wallet", and the project README is titled "Open Source Monero-Only Wallet". Because the app does not provide a Bitcoin wallet, it is out of scope for Bitcoin verification and we assign the verdict **nobtc**. It is built from the same repository that produces the multi-currency Cake Wallet, which is covered separately.
