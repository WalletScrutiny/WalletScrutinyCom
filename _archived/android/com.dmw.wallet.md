## App Description

The app's description is very sparse: 

> Securely manage your crypto assets in one app.

## Analysis

The app's user interface is primarily a signup wall. Both the Play description and the website barely have enough information on them. We did not receive the sms verification. The developer's email address lists the domain dmwmainnet. We checked it out and it seems to display transactions on its own blockchain. The latest transaction was 11 days ago from the date of review. 

On the Play Description image, it at least shows the coins it supports:

WCGC - WeChatGoCoin
WFCP - WFCPAY
WFA - WorldFriendship
ADTD - AdamantDiamondToken

This is **not a Bitcoin wallet**.
