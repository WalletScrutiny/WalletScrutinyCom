## App Description

Defi App is a self-custodial multi-chain wallet and trading platform developed by Dark Matter Digital Limited (British Virgin Islands). It provides users with a 12-word seed phrase and claims to combine centralized exchange speed with self-custody.

## Supported Networks

Ethereum, Arbitrum, BNB Chain, Base, Solana, and Sonic. Bitcoin is not supported.

## Analysis

Despite the Play Store listing mentioning Bitcoin among tradable assets, the [official documentation](https://docs.defi.app/knowledge-base/reference/supported-tokens-and-networks) confirms Bitcoin and the Bitcoin network are not supported. All six supported chains are EVM or Solana-based.

The app is self-custodial (seed phrase provided) but no source code is available.

## Verdict

Defi App **does not support Bitcoin**. It is a self-custodial EVM/Solana wallet with no published source code.
