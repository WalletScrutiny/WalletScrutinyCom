## App Description

Paytaca is a non-custodial cryptocurrency wallet focused on the Bitcoin Cash (BCH) blockchain. It allows users to create or import wallets, generate private keys locally, and send or receive BCH transactions on-chain. The application is available on mobile and web platforms and supports QR-based payments for peer-to-peer transfers and merchant transactions. Users retain control of their private keys within the wallet environment, enabling direct interaction with BCH-based applications and services.

This is a BCH wallet and **not a BTC wallet**.
