## App Description

Peniwallet claims in its app description that is a decentralized, non-custodial cryptocurrency wallet that gives users full control of their private keys and interfaces directly with public blockchains for asset management. 

The wallet includes a unique “Spray” feature for sending tokens to many addresses in one transaction and supports swaps via decentralized exchange aggregators without custody of user funds. While marketed as secure and user-controlled, the wallet’s documentation highlights current support primarily on specific chains (e.g., BNB Chain)

## Analysis

We tested the app and [did not find a Bitcoin wallet](https://x.com/BitcoinWalletz/status/2011720358240665868/photo/3).
